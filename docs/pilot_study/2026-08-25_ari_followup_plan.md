## A2：连续化敏感性检验 ✅ 已完成（2026-08-25）→ [报告](2026-08-25_ari_a2_continuum.md)

- **动机**：A1 的 realized 二分类依赖特定裁决阈值（0.1×声道最大 RMS、0.1-0.5s 跨度规则）。
  阈值敏感性未知；且 A1 的"随机水平附近"结论需要连续量佐证。
- **设计**：
  1. 特征（含 dur）与 `both_active_frac` 的 Spearman 相关 + bootstrap 95% CI（BC/Int 分开）；
  2. realized 阈值敏感性：y = frac > τ，τ ∈ {0, 0.05, 0.1, 0.2, 0.3}，重算全特征 / 无 energy_ratio /
     仅事件声道特征三组 AUC，画 AUC-τ 曲线；
  3. 对比 expected：energy_ratio 与 frac 强相关（构造性），事件声道韵律特征 ≈ 0 相关。
- **决策点**：若韵律特征在任何阈值/连续量下都 ≈ 随机 → A1 结论加硬；若某些阈值下可分 →
  A1 结论需限定。**实际结果**：低 τ（任何重叠）≈ 随机，A1 稳健；高 τ（实质重叠）可分性
  上升（BC 0.64 / Int 0.73）→ A1 结论加上"典型渲染量级（短暂重叠）下无韵律印记"的限定。
- **状态**：✅ 2026-08-25 完成。

## B：特征归因与消融

- **动机**：主实验 ΔARI=−0.25 由哪几个特征支撑？"None 类静音捷径"贡献多大？
- **设计**：
  1. 主实验三分类 ARI 的消融：全特征 / 去 energy_ratio / 去 F0 组 / 仅事件声道特征，
     每组合跑 B=200 bootstrap（复用 `ari_analyze.py`，加 `--drop` 参数）；
  2. 报告 Behavior-SD 与 CANDOR 在每组特征下的 ARI 变化曲线。
- **预期**：Behavior-SD 的 ARI 去掉 energy_ratio 后大幅坍缩（→ ~0.1），CANDOR 变化不大
  （本就接近随机）。若成立，"合成数据的可判别性主要来自声道静音捷径"被量化。
- **决策点**：论文中主指标是否应报告"去 energy_ratio"版本；静音捷径警告的证据强度。
- **状态**：✅ 2026-08-25 完成 → [报告](2026-08-25_ari_b_ablation.md)。**实际结果**：
  能量比单独承载 Behavior-SD 0.314/0.309（与全量相当）；去掉后坍缩到 0.050；
  其余全部特征（含韵律）两数据集均 ≈ 随机。静音捷径假设完全坐实；
  且 F0 类特征对两数据集聚类均只有噪声贡献（all < no_f0 / energy_only）。

## C：跨数据集迁移（静音捷径的实质检验）

- **动机**：B 若成立，Behavior-SD 上学到的判别边界应无法迁移到有串扰的真实录音。
  这是对 full-duplex benchmark 评估方式的实质批评，也是论文最有杀伤力的一张表。
- **设计**：
  1. 在 Behavior-SD 平衡抽样上训练 LogisticRegression（三分类或 BC-vs-rest）；
  2. 零样本评估到 CANDOR（同特征、同标签空间）；报告混淆矩阵与 macro-F1；
  3. 反向（CANDOR → Behavior-SD）作为对照。
- **预期**：Behavior-SD → CANDOR 大幅退化（macro-F1 接近随机）；反向略好但仍差。
- **决策点**：benchmark 论文的"分布偏移/捷径"论点。
- **状态**：✅ 2026-08-25 完成 → [报告](2026-08-25_ari_c_transfer.md)。**实际结果**：
  B→C 0.447（域内 0.718→退化 0.27）；无能量比时归零（0.344≈随机）；**C→B 0.636
  高于 CANDOR 域内 0.524**——人类数据学到的边界更稳健，CANDOR 域内上限受标签噪声限制
  （为 D 提供动机）。

## D：强化人类基线

- **动机**：CANDOR ARI ≈ 0.06 接近随机，但每类特征均值显示文献线索存在（BC 音高下降 −61 Hz/s）。
  是标签噪声+串扰淹没了线索，还是这套特征对人类数据本就不足？决定论文中人类基线如何表述。
- **设计**：
  1. 清洗：按会话级声道能量比/串扰指标（如对方声道在 None 事件中的 RMS 中位数）过滤
     "干净"会话子集，重算 ARI；
  2. per-session z-score 特征后再聚类（去除说话人/响度因素）；
  3. 若回升明显 → "差距 = 标签质量+串扰"归因坐实；若仍在随机附近 →
     "真实 BC/Int 对这些特征本就难"同样可发表。
- **状态**：✅ 2026-08-25 完成 → [报告](2026-08-25_ari_d_human_baseline.md)。**实际结果**：
  人类基线几乎不可修复——最强变体（干净档+z-score）仅 0.074（全量 0.058）；
  串扰有方向性但非主因（干净 0.063 vs 嘈杂 0.046）；BC-vs-Int 完全不动（0.030→0.031）。
  结论：本特征集下人类 BC/Int/None 无监督结构上限 ≈0.07，ΔARI 差距不是人为压低。

## E：合成 BC 韵律缺陷验证（小、快）

- **动机**：合成 BC 的音高下降弱于人类（−14 vs −61 Hz/s）。是 TTS 韵律控制问题还是文本选择问题？
- **设计**：对照 BC token 文本（"sure."/"yeah." 天然降调）与实测 F0 斜率分布；
  若文本语义应降调而实测平坦 → TTS 韵律缺陷（可直接进论文的小发现）。
- **状态**：✅ 2026-08-25 完成 → [报告](2026-08-25_ari_e_prosody_text.md)。**实际结果
  （部分推翻主报告 §3.2 的均值解读）**：人类 BC 文本无关地平坦（中位 −7.7）；
  合成 BC 词汇驱动模板化（中位 −29.2，okay/hmm 强降、mhm/really 强升+74/+87——
  升调附和语义不当）。主报告 §3.2 已加更正注。
