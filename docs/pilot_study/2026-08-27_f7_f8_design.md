## 1. F7：模型输出的鲁棒评测 harness

**目标**：把 F6 指标对 (BCRR, BCA) + TBR 应用到**模型输出流**。

流程（全自动，复用现有管线）：
1. 模型在 CANDOR 会话上产生回复音频（输入 = 宿主声道音频流）
2. 对模型输出跑 L3 融合标注（X2-Turn + SoulX）→ 帧级状态
3. 计算指标：BCRR（模型做 BC 的密度）、BCA（模型 BC 与宿主语音的真实对齐——
   对模型输出+宿主音频做声道级双活跃裁决）、TBR（宿主 turn_end → 模型发声延迟，
   用 X2-Turn 的 turn_end 状态）
4. 附无捷径对照协议四件套（Table 1）

**前置依赖**：F8 的模型（或任何现成全双工/半双工模型）——因此 F7 与 F8 绑定，
先用基线模型跑通 harness，再评测后训练模型。

## 2. F8：后训练范式（数据侧已就绪，模型侧待决策）

**数据**（`ari_f8_prep_data.py` 生成中）：
- CANDOR-FD 100 会话 → 每声道 10s 块（5s 步进），每块含：
  - 16k mono 音频
  - 每 80ms 帧的三态软标签 [p_idle, p_speak, p_bc]（X2-Turn 概率）
  - fused 分数（30 会话处，F1 mean 配方）
  - X2-Turn 转写（80 会话）
- 规模预估：100 会话 × 2 声道 × ~27min ≈ 90h 单声道音频 → ~3.2 万块

**训练任务形式（三选一，见决策清单）**：
- **A. 辅助头**：冻结主干 + LoRA + 帧级三态分类头（最轻，~80ms 粒度，适合
  "何时说话/附和"的决策学习）
- **B. 触发 token**：在语音 LM 的输出序列中预测 `<speak>`/`<backchannel>`/
  `<listen>` 特殊 token（与模型生成路径深度耦合，最贴近部署形态）
- **C. 时序回归**：预测下一话轮起始时刻/BC 概率曲线（中间态）

**双基线**（F9 的对照设计，训练脚本应预留）：
1. 真实 L3 标注训练（本数据）
2. 合成 metadata 标注训练（Behavior-SD 同规模同任务——预言：效果差于 1）
3. 无训练基线
