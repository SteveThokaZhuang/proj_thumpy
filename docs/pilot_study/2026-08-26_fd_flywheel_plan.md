# 全双工数据飞轮：从标签审计到真实能力（故事扩展与实验计划）

> **日期**：2026-08-26
> **定位**：在 [论文故事](2026-08-25_paper_story.md)（三幕审计）基础上扩展的
> **正向故事线**。目标不再是"证明评测不可信"，而是给出可信评测的完整方案，
> 并让数据闭环反哺模型能力：**审计 → 标注范式 → 鲁棒指标 → 数据飞轮 →
> 分数-能力一致性**。
> **论文拆分**：Paper 1 = 审计（已成型）；Paper 2 = 标注范式 + 鲁棒指标 + 基准发布；
> Paper 3 = 数据飞轮训练 + 一致性验证。

---

## 1. 核心叙事

> *"我们审计发现全双工评测测的是标签继承而非模型能力（Paper 1）。本文给出修复：
> 用合成金标准校准的模型化标注器融合，为真实语音做鲁棒全双工标注（范式）；
> 在该标注上定义带无捷径对照的评测指标（评测端）；用产出的标注数据轻量后训练
> 半双工模型使其获得全双工能力（数据飞轮）；最终证明鲁棒指标的高分对应
> 人类听测中的真实全双工能力（一致性）。"*

**机制级预言**（Paper 1 的发现直接给出的可检验假设）：
合成数据无交互韵律（A1/A2：重叠不写入 token 韵律）、韵律=词条模板（E）、
标签-声学一致性 84% 由静音捷径承载（B）→ **用合成 metadata 训练的模型学到的
是"干净声道里的 BC 形 token"，而用 L3 标注的真实数据训练的模型学到的才是
"在对方说话时恰当地发声"**。F9 的双基线实验直接检验此预言。

## 3. 实验清单（F1-F10）

### Paper 2：标注范式与鲁棒指标

| # | 实验 | 内容 | 产出 | 优先级/估计 |
|---|---|---|---|---|
| **F1** | 标注融合算法 | ✅ 2026-08-26 完成 → [报告](2026-08-26_f1_fusion.md)。概率加权融合 w=0.7 全面最优：帧 AUC 0.629、窗口 AUROC **0.811**（vs 单标注器 0.733/0.633）、覆盖率 0.57；max 融合最差；硬交集（E5）与软加权（F1）的对照闭环 | 融合配方 w≈0.7 + 帧级软分数输出 | ✅ |
| F2 | 规模化标注 + 基准发布 | ✅ v0 2026-08-27 完成 → [报告](2026-08-27_f2_candor_fd.md)。**CANDOR-FD v0**：100 会话 / 6,570 个 BC 窗口；X2-Turn 全会话帧+转写（80 会话），SoulX 30 会话（1,672 区域），AWS/realized 全量；产物 `annotator/candor_fd_v0/`。扩展至 300 会话可随时续跑 | CANDOR-FD 基准 v0 | ✅（可扩展） |
| F3 | 人工验证 | 抽样 200-500 个 BC 窗口人工核对融合标注 vs realized | 标注质量黄金标准 | 🟠 1 周（需人力） |
| F4 | Oracle ASR 归因 | ✅ 2026-08-26 完成 → [报告](2026-08-26_f4_asr_attribution.md)。金标准侧：子串对齐 WER 中位 0.046（固定对齐 0.83 系流式缺头伪影）；r(WER, AUC)=−0.27 p=0.13 不显著——ASR 非瓶颈，状态头是主因。CANDOR 侧待 F2 转写完成后补 | 归因表 | ✅ |
| F5 | 跨域鲁棒性 | ✅ 2026-08-27 完成 → [报告](2026-08-27_f5_fisher.md)。Fisher 28 对话：speaking AUC 0.839（>CANDOR 0.695——人工转写边界更干净）、BC AUC 0.616、WER 0.33（ASR 恶化 7 倍但状态几乎不降——状态头鲁棒性 ≫ ASR 头） | 跨域 AUC 表 | ✅ |
| F6 | 指标定义 + 敏感性 | ✅ 2026-08-26 完成 → [报告](2026-08-26_f6_metrics.md)。指标对 (BCRR, BCA) 互补且必须成对报告：BCRR 响应延迟/漏检但被误报抬高；BCA 响应延迟≥1s/误报但对漏检弱；灵敏度下限 ~1s。v0=标注噪声鲁棒性；行为敏感性待 F7 | 指标对 + 响应特性表 | ✅ |

## 5. 风险

- F3/F10 需要听测人力与经费（团队资源待确认）
- F9 的"真实标注 > 合成标注"是强预言但非保证；若不成立，故事退化为"标注质量与
  训练增益解耦"（也有价值但弱一档）
- 标注质量→训练增益的传导率未知：任务形式（辅助头 vs 触发 token）、数据量、
  采样策略需要烧实验（F8 的探索成本可能高于估计）
- 全双工能力的人类听测标准本身缺乏成熟量表（F10 需自建或借用 FD-Bench 主观维度）
