# 工作故事线总报告：从声学审计到数据飞轮（2026-08-23 ～ 08-28）

> **一句话故事**：*全双工对话评测的分数取决于"标签从哪来"——我们审计了三层
> 标签源，证明合成标签是捷径、声学标签是噪声、模型化标注器才是正解；并把这个
> 诊断闭环成一条数据飞轮：用合成金标准校准标注器 → 标注真实对话 → 用真实标注
> 轻量后训练半双工模型 → 让评测分数重新对应真实能力。*

| 实验 | 核心结果 |
|---|---|

## 2. 三条核心科学结论

1. **捷径定理**：合成数据的"可评测性"84% 是一个静音捷径——评测模型 = 听对方声道
   有没有声音。捷径不迁移、不教行为、且污染指标（E2：25 倍漂移、10% 串扰归零）。
2. **标签层级定理**：评测指标的可信度 = 所用标签层级的可信度。L1 生成端 GT（完美
   但捷径化）、L2 声学派生（工具链决定，κ 0.06-0.37）、L3 模型化标注器（与声学
   现实对齐最好，AUROC 0.667）——**L3 是真实数据的唯一正解**。
3. **任务形式定理**：训练增益从"标签"传导到"行为"的关键不是标签量而是**任务形式**——
   词序列任务（任何粒度）行为层 ≈ 随机；事件式任务（预测 BC 时间戳）第一次打通
   传导（F1 0.124）。同时"真实标注 > 合成标注"的预言在词序列（F9）与事件（F9 事件）
   两个任务形式下都成立。
