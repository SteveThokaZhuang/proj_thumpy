# F2：CANDOR-FD v0——真实对话全双工行为标注基准

> **日期**：2026-08-26（推理）～ 2026-08-27（打包）
> **动机**：[数据飞轮计划](2026-08-26_fd_flywheel_plan.md) Paper 2 的数据基础：
> 把模型化标注器扩展到 100 个真实会话，产出分层标注的基准。
>
> **产物**：`real_data/results/annotator/candor_fd_v0/`（index.json + summary.json + README）
> 推理产物：`e4_raw/`（100 会话 X2-Turn 帧+转写）、`f2_soulx_regions/`（30 会话 SoulX 状态）

---

## 1. 构成

| 层 | 内容 | 覆盖 |
|---|---|---|
| AWS（L2 参考） | backbiter/audiophile 派生标签 | 全部事件 |
| realized（声学验证） | 声道级 RMS 双活跃裁决（E1） | 全部事件 |
| **X2-Turn（L3 主标注）** | 80ms/帧 6 类状态 + p(backchannel)/p(speaking) + 转写 | **100 会话**（80 个含转写） |
| **SoulX（L3 补充）** | 160ms/块 backchannel 状态（级联 SenseVoice） | **30 会话**（1,672 个 BC 邻域区域） |
| fused（L3 融合） | mean 融合软分数（F1 配方） | SoulX 可用处（脚本重算） |

**统计**：100 会话，6,570 个 AWS BC 窗口。

## 2. 推理与工程记录

- X2-Turn：3 分钟分块 + 30s 重叠（显存安全），断点续跑，全会话帧 + 转写
  （E4 旧 20 会话无转写，80 个新会话含转写——供 CANDOR 侧 F4 对照）。
- SoulX：BC 窗口 ±5s 邻域区域（1,672 个），级联 SenseVoiceSmall
  （本地权重 + modelscope 缓存符号链接，见 E5 部署记录）。
- 全程 gpu01（kimi 作业 45764）持久步骤内执行，login01 未跑计算。

## 3. 用途

1. **Paper 2 标注范式**：F1 融合配方在此基准上可完整复现
   （30 会话融合层 + 100 会话主标注层）；
2. **Paper 2 评测端**：F6 指标对（BCRR, BCA）的规模化计算；
3. **Paper 3 数据飞轮**：F8/F9 后训练实验的标注数据来源；
4. **F4 补充**：80 会话的 X2-Turn 转写 vs AWS audiophile 文本（子串对齐口径）
   做真实侧 ASR 归因。

## 4. 局限

- v0 的 SoulX 只覆盖 BC 邻域区域（窗口化推理），Int/None 事件的 SoulX 层缺失；
- 20 个旧会话（E4 期）无 X2-Turn 转写；
- 未含人工验证层（F3 待做）。
