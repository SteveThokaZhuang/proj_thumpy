# 方向 1：基于残差分析的维度发现（设计文档）

> **状态**: 草稿 v0.1（待评审） · **日期**: 2026-08-23
> **数据基础**: Behavior-SD（`/share/workspace3/shared_dataset/behavior-sd`）
> **目标**: 在不预设新标签的前提下，从现有标注 (BC / Int / None) 的模型残差中发现潜在标注维度，为 finegrid 标注体系提供候选维度。

---

## 1. 核心假设

若现有标签体系 {BC, Int, None} 对 Behavior-SD 数据是**完备**的，那么：

1. 用这些标签训练的预测模型，其残差应近似**随机**（只可归因于标签噪声与模型容量）；
2. 若残差呈现**系统性模式**（某类样本反复朝同一方向预测错、且错法可聚类），说明数据中存在现有标签**未覆盖的潜在维度**；
3. 对残差样本聚类 → 归纳簇画像 → 命名 → 得到候选新维度，再回到人类语料中验证其是否真实存在。

一句话：**模型是现有标签体系的"镜子"，系统性残差是未标注维度的指纹。**

---

## 2. 背景与动机

### 2.1 已知结论（pilot_study，截至 2026-08-23）

- 生成标签 → 元数据时间线 **100% 一致**；真正的不一致发生在**元数据区间 vs 声学渲染**之间；
- Backchannel 标称 ~4–5s/条，实际同时发声仅 **~15%**（≈0.6s/条），其余被渲染进宿主话轮的停顿中；
- pyannote 是合格的重叠检测器（GT vs 检测重叠总量 Pearson r = 0.855），但相对 GT 区间低估（2.21s vs 4.42s，过分割导致）。

### 2.2 为什么怀疑现有 3 类不完备

- "Int" 不区分：重叠后**是否成功抢走话语权**（floor taken or not）、重叠长短；
- "BC" 不区分：标称长但几乎不同时发声（渲染 artifact）与真实短反馈；
- 类内方差大 → 模型要拟合好就不得不"发明"内部结构；残差正是这些内部结构的痕迹。

### 2.3 为什么用残差分析而不是直接对全量数据聚类

直接聚类会被已标注的 3 类主导（BC/Int/None 之间的差异远大于类内细分）。残差分析相当于**先扣除已知维度，再看剩下什么**——把发现能力聚焦在"现有标签未解释的方差"上。

---

## 3. 总体流程

```
Step 1                Step 2                 Step 3               Step 4
基线模型训练      →   残差模式分析       →   残差样本聚类     →   维度归纳与验证
(声学+文本+上下文)    (系统性高估/低估)     (两组分别聚类)        (命名 + 人工验证 + 闭环)
```

四步详细设计见 §4–§7，风险与工程落地见 §8–§10。

## 4. Step 1：基线模型

### 4.1 样本与标签

- **样本单元**: 对话级（file_id），与现有标签派生口径一致；
- **标签派生**（沿用 `run_real_pipeline.py` 口径）:
  `total_int > 0 → Interruption; elif total_bc > 0 → Backchannel; else None`；
- **数据范围**: validation (2 tar ≈ 1,000 对话) + test (2 tar ≈ 1,000) 先跑通原型；再扩展到 train 已处理子集 (64 tar ≈ 32,000)。

### 4.2 特征组（三组）

所有特征**只用"输入侧"信息**，禁止使用标签自身或其直接派生量（防泄漏）。

**A. 声学特征**（复用 `real_data/results/{split}/diarization/*.json`）

- 重叠事件: 个数、总时长、最大时长、占对话时长比、时长分布分位数；
- 话轮结构: 话轮数、平均话轮时长、交替间隔分布；
- （可选）声道级活跃性: 复用 `verify_backchannel.py` 的 RMS 口径，计算双声道同时活跃时长占比 —— 这是"BC 是否真的同时发声"的直接证据。

**B. 文本特征**（复用 `transcription/*.json` 词级时间戳）

- 词数、语速 (words/sec)、filler 密度（uh/um/you know 命中率）；
- BC 词典命中: yeah / uh-huh / right / mhm / oh / wow / really 等及其出现位置；
- 重叠区词内容（与 diarization 重叠区间对齐后的词）。

**C. 上下文特征**（官方 metadata JSON）

- `statistics` 字段: num_utterances / num_turntaking / durations / num_filler_words；
- `uttr_type == "interrupt"` 的 utterance 数与占比；
- 说话人角色、narrative 长度、num_turns；
- **事件级明细**（供 Step 2 归因用）: 每个 utterance / bc 事件的时间戳、时长、嵌套关系。

> 可选增强: narrative 或 tts_text 的语义嵌入（冻结的 sentence encoder）。若某维度只体现在语义层（如 BC 的情感/认知功能），纯词面特征可能看不到 → 见 §8 风险 2。

### 4.3 模型与训练协议

- 模型: **LightGBM 多分类**（可解释 + 概率输出 + 快）；逻辑回归作可解释性对照；
- **分层 5 折交叉验证**，全部预测取 **OOF 概率**（避免折内泄漏）；
- 概率校准: isotonic regression（按类），报告校准曲线 + ECE；
- 评估: macro-F1、混淆矩阵、逐类 P/R。

> **定位声明**: 模型精度不是目标；概率的**可靠性**与残差的**稳定性**（跨折一致）才是。若残差在折间不稳定 → 样本量不足或特征噪声过大，先回到特征工程。

## 5. Step 2：残差模式分析

### 5.1 残差定义（软 + 硬双通道）

| 通道 | 定义 | 用途 |
|------|------|------|
| 硬残差 | 混淆矩阵 off-diagonal 单元（**含方向**: Int→BC ≠ BC→Int） | 总量与方向性概览 |
| 软残差 | 逐样本 log-loss 贡献 `-log P(y|x)`；方向性 margin `P(pred) − P(y)` | 样本级排序与筛选 |

### 5.2 系统性高估 / 低估的操作定义

- **高估样本（预测 Int，标注 BC）**: 模型"看到"了比标签更强的行为。操作定义: 标签 BC，且校准后 P(Int) 超过 **BC 样本** P(Int) 分布的 90 分位（按类内分位定义，天然规避类不平衡）。对称地，标签 None 但 P(Int) 或 P(BC) 异常高 → 漏检残差。
- **低估样本（预测 BC，标注 Int）**: 标签"承诺"了模型看不到的行为。操作定义: 标签 Int，且校准后 P(Int) 低于 **Int 样本** P(Int) 分布的 50 分位。对称地，标签 BC 但 P(BC) 低。
- 残差分数 `r_i = −log P(y_i|x_i)` 排序取尾部（初始值 top 5%）作为残差集，再按方向分桶。

### 5.3 系统性检验（区分"系统性"与"随机噪声"）

- **置换检验**: 随机打乱标签训练 K 次，得到 r 的零分布；真实残差尾部显著超出零分布 → 系统性；
- **Bootstrap CI**: 残差集特征统计量的置信区间，验证模式跨折 / 跨 split 稳定；
- 若高估/低估不显著 → 输出"未发现系统性残差"本身也是有效结论（支持标签完备性假设）。

### 5.4 残差归因（对话级 → 事件级）

对话级残差需归因到具体事件才能聚类（对话级特征太粗）。做法：

- SHAP（TreeExplainer）给出特征贡献方向；
- 结合事件级特征（哪个 utterance 是 interrupt、哪个 bc 事件长、哪个重叠长）人工核对 top-K 样本；
- 产出**残差画像表**: `(file_id, 标签, P(y), r_i, 方向, 关键事件, 特征贡献)`。

---

## 6. Step 3：残差样本聚类

### 6.1 分组聚类（高估组与低估组分开）

高估与低估代表**不同的潜在维度**（前者是"标注之下隐藏的强行为"，后者是"标签过强的弱行为"），混在一起聚类会互相污染。两组各自独立聚类。

### 6.2 聚类特征

用**行为可解释的低维特征子集**（可解释性优先于纯度）：

- 重叠类: 重叠总时长、最大时长、0.1–0.5s 短重叠个数、>0.5s 长重叠个数；
- 时序类: 事件发生位置（对话前/中/后 1/3）、重叠后原说话人是否继续（floor taken 代理）；
- 文本类: BC 词典命中次数、BC 事件文本长度（词数）、filler 密度；
- 上下文类: `uttr_type=interrupt` 计数、num_turns、说话人角色。

### 6.3 方法

- 主方案: **HDBSCAN**（簇数自动、容忍噪声点）+ UMAP 降维可视化；
- 备选: KMeans（k = 2..6，按 silhouette / 稳定性选 k）；
- 噪声点不强行分配 —— 归入"未解决方差"池，见 §8。

### 6.4 簇画像与质量门槛

每簇输出：

- 特征均值对比表（簇 vs 残差集整体 vs 全样本）；
- 3–5 个代表性样本（file_id + 关键事件时间戳，可直接回放音频复核）。

**质量门槛**（不满足则不做维度归纳）：

1. 簇样本量 ≥ max(5, 残差集 1%)；
2. 簇内方差显著小于全局（至少一个关键特征上）；
3. 画像可被一句话命名。

## 7. Step 4：维度归纳与人工验证

### 7.1 命名规范

每个候选维度必须有**可操作定义**: 声学证据 + 语义/功能特征 + 与现有 3 类的边界判别规则。拒绝纯统计标签（"cluster 3"不是维度名）。

### 7.2 候选维度示例（预注册假设）

> "预注册": 候选维度在聚类**之前**写下预期画像，聚类后对比 —— 防止事后讲故事。

| 候选名 | 方向 | 预期画像 | 已有证据线索 |
|--------|------|----------|--------------|
| **Short-Interruption** | 高估（预测 Int，标注 BC） | BC 样本中夹带 0.1–0.5s 短重叠、有抢话特征 → 模型判 Int | pyannote 过分割产生大量短重叠；BC 类内实际同时发声 ~15% 的分布尾部 |
| **Extended-Backchannel** | 低估（预测 BC，标注 Int） | Int 样本中的"打断"实为支持性长反馈，原说话人继续说话 → 模型判 BC | BC 标称 4–5s vs 实际 0.6s 的方差；Int 类内 floor-taken 与否的方差 |

另可补充两个延伸假设（M2 聚类时顺带检验，不强求）：

- **Failed-Interruption**: 存在长重叠但未成功抢走话语权（floor not taken）—— 与 Short-Interruption 构成"时长 × 成功"的 2×2 结构；
- **Pseudo-Backchannel**: 标称 BC 但几乎无同时发声（渲染进停顿）—— 若成立，这更可能是**标签定义需收紧**问题而非新维度（见 §8 风险 1）。

### 7.3 独立性判定（细分 vs 正交）

对每个候选维度判定它与现有 3 类的关系：

- **细分轴**: 同一行为轴上的细化（如 Int → {Short-Int, Full-Int, Failed-Int}）；
- **正交轴**: 与行为类型无关的新属性（如 BC 的功能维度 emotive / cognitive）。

这决定 finegrid 标签体系是"扩类"还是"加轴"。

### 7.4 人工验证（语料批下后）

- **抽样**: 每候选维度抽 20–30 个残差样本 + 等量对照样本，双人重标注；
- **指标**: 标注者间一致率（Cohen's κ）；残差簇与人工新标签的对应率（ARI）；
- **判定**: 若簇在人类标注中**不可复现** → 丢弃该候选维度；
- **闭环**: 新维度并入标签体系 → 重训基线模型 → 残差应显著消解。残差消解幅度 = 新维度解释力的量化证据，也是整个方向 1 的最终验收指标。

## 8. 风险与对策

| 风险 | 后果 | 对策 |
|------|------|------|
| 残差来自标签噪声/渲染伪影而非真实维度 | 归纳出"假维度" | 用 GT 时间线交叉验证；能被已知 artifact（如 BC 渲染进停顿）完全解释的簇 → 归为"标签定义需收紧"，不是新维度 |
| 某维度在现有特征中不可见 | 残差发现不了 | 补充语义嵌入特征；接受方法边界: 残差分析只能发现"特征可见"的维度 |
| 类不平衡（None 对话占比高） | 残差集被 None 主导 | 按类内分位定义残差阈值（§5.2 已内建）；分层抽样 |
| 残差集太小 / 折间不稳定 | 聚类无意义 | 扩到 train 子集（64 tar ≈ 32,000）；先做稳定性检查再聚类 |
| 簇不可命名 | 无法归纳维度 | 不强行命名，归入"未解决方差"池，留待语料人工标注时重新审视 |

## 11. 待定问题（评审时确认）

1. **建模粒度**: 主模型对话级 + 归因事件级（本设计默认），是否需要事件级辅助模型？
2. **残差阈值**: 90/50 分位、top 5% 是初始值，M2 用数据校准；
3. **None 类残差**: 是否把"标签 None 但 P(BC/Int) 高"的漏检样本也纳入聚类（建议纳入）；
4. **语料批下时间**: M4 依赖于此；
5. **与后续方向的关系**: 若另有文献/理论驱动的维度先验（方向 2/3…），本方向的残差簇应与理论先验**互相印证**——先验命中残差簇 → 强化证据；未命中 → 各自复核。
